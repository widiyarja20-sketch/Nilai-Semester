# 🧮 Aplikasi Hitung Nilai Semester

Aplikasi berbasis CLI (Command Line Interface) sederhana yang ditulis dalam bahasa **Python** untuk menghitung nilai akhir mahasiswa berdasarkan bobot persentase tugas, UTS, dan UAS, serta menentukan grade akhir.

## 📊 Bobot Penilaian
* **Tugas:** 20%
* **UTS:** 30%
* **UAS:** 50%

## 📂 Rentang Grade
* **A**: Nilai Akhir >= 85
* **B**: Nilai Akhir >= 70
* **C**: Nilai Akhir >= 55
* **D/E**: Nilai Akhir < 55

## 🚀 Cara Menjalankan Aplikasi

1. **Clone repositori ini** atau unduh file `app.py`.
2. Pastikan Anda sudah menginstal [Python](https://python.org).
3. Buka Terminal atau Command Prompt di folder tempat file berada.
4. Jalankan perintah berikut:
   ```bash
   python app.py
   ```
